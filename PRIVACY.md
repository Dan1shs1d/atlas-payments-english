# Privacy

Atlas Payments English supplies instructions and local reference text. It adds no telemetry, analytics SDK, network service, credential store or payment-data storage. It does not receive documents at a project-operated server.

The host model processes what you submit. Host data handling, retention, training controls, subprocessors and organizational settings still apply. Local installation does not mean local AI inference. No claim of PCI DSS, GDPR, SOC 2 or other compliance is made.

Do not paste live payment-account data, authentication data or secrets. Use redacted samples. Do not put private texts into GitHub issues, pull requests, evaluation submissions or published response logs. Maintainer response grading reads local files only; users choose whether to save model responses.
